# Documentation and NEWS

## man/ and NAMESPACE are generated — never hand-edit

Both `NAMESPACE` and every file in `man/` carry roxygen2's
`Generated by roxygen2: do not edit by hand` header. Regenerate with:

```r
roxygen2::roxygenise()
```

> **Check your roxygen version first.** Compare `packageVersion("roxygen2")` against
> `DESCRIPTION`'s `RoxygenNote`. If they differ, **stop and tell the human.** Regenerating
> with a different roxygen rewrites all 100+ man pages and bumps `RoxygenNote`, producing a
> huge diff unrelated to your change. A roxygen upgrade is its own dedicated PR — it must
> never ride along in a work PR.

If you believe `NAMESPACE` needs an export that roxygen is not producing, the fix is an
`@export` tag in the `R/` source, not an edit to `NAMESPACE`.

## roxygen requirements for exported functions

Every exported function needs `@title`, `@description`, `@param` (all arguments),
`@return`, and at least one **runnable** `@examples` block.

- Examples use the shipped `exampleMouse` / `exampleTumourNormal` data objects.
- Avoid `\dontrun{}` unless the example genuinely needs network access or external files.
  BiocCheck flags unnecessary `\dontrun{}`.
- Add `@seealso` cross-references to related functions.
- Roxygen comment lines wrap at ≤ 100 chars (R code wraps at ≤ 80).

## NEWS.md

Record **every user-visible change** under the current devel heading, in the same PR that
makes the change.

Structure — `#` for the version, `##` for the category:

```markdown
# mesa 0.99.6.9000

## Bug fixes
- `calculateCGEnrichment()` no longer calls `MEDIPS`. Reads are imported directly with
  `Rsamtools::scanBam()` and CpG positions located with `Biostrings`.
  ([#81](https://github.com/cruk-mi/mesa/issues/81))
```

Conventions:

- Categories in use: `## Bug fixes`, `## New features`, `## Documentation`, `## Testing`,
  `## Infrastructure`, `## Style`. Reuse an existing spelling rather than inventing one —
  the file already has both `## Bug fixes` and `## Bug Fixes`; prefer **`## Bug fixes`**.
- Function names in backticks with parentheses: `` `makeQset()` ``.
- Close each entry with a linked issue or PR reference:
  `([#NN](https://github.com/cruk-mi/mesa/issues/NN))`.
- Describe the **user-visible effect**, not the implementation. State what changed for
  someone calling the function.
- Write entries under the existing devel heading. Creating or renaming a version heading is
  a release action — see `bioc-release-cycle`.
